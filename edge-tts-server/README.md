# EdgeTTS Server - Free Text-to-Speech for Development

A lightweight, free Text-to-Speech API server using Microsoft Edge's TTS engine. **No API keys, no billing, no authentication required**.

Perfect for development, testing, and production use without costs.

## Features

✅ **Completely Free** - No API keys or billing required  
✅ **High Quality** - Uses Microsoft Edge's neural TTS engine  
✅ **Multiple Languages** - 10+ languages with multiple voices each  
✅ **Easy Setup** - Docker or standalone Python  
✅ **Fast** - Lightweight and responsive  
✅ **Offline Capable** - Runs locally, no external dependencies

## Quick Start

### Option 1: Docker Compose (Recommended)

```bash
# From project root, start all services
docker-compose -f docker-compose.dev.yml up -d

# EdgeTTS will be available at: http://localhost:5001
# Backend configured to use EdgeTTS automatically
```

### Option 2: Docker Only (EdgeTTS Server)

```bash
# Build and run just the EdgeTTS server
docker build -t edge-tts-server ./edge-tts-server
docker run -p 5001:5001 edge-tts-server
```

### Option 3: Standalone Python

```bash
# Install dependencies
cd edge-tts-server
pip install -r requirements.txt

# Run the server
python app.py

# Server runs at http://localhost:5001
```

## API Usage

### Health Check
```bash
curl http://localhost:5001/health
# Response: {"status": "healthy", "service": "EdgeTTS"}
```

### List Available Voices
```bash
curl http://localhost:5001/voices
```

### Text-to-Speech (Generate Audio)

**Request:**
```bash
curl -X POST http://localhost:5001/tts \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello, this is a test",
    "voice": "en-US-AriaNeural",
    "rate": "1.0"
  }' \
  -o output.mp3
```

**Parameters:**
- `text` (required): Text to convert to speech (max 5000 characters)
- `voice` (optional): Voice name from available voices list
- `rate` (optional): Speech rate 0.5 to 2.0 (default: 1.0)

**Response:** MP3 binary audio file

## Integration with Language Assessment App

### Configuration

The backend is automatically configured to use EdgeTTS in `application.yml`:

```yaml
tts:
  provider: ${TTS_PROVIDER:edge}
  edge:
    api:
      url: ${EDGE_TTS_API_URL:http://localhost:5001/tts}
```

### Environment Variables

```bash
# Use EdgeTTS (default for development)
TTS_PROVIDER=edge
EDGE_TTS_API_URL=http://localhost:5001/tts

# Or use Google Cloud TTS (requires API key and billing)
TTS_PROVIDER=google
GOOGLE_TTS_API_KEY=AIza...

# Or use ElevenLabs (requires API key)
TTS_PROVIDER=elevenlabs
ELEVENLABS_API_KEY=your-key
```

## Workflow

1. **Admin creates and generates questions** for LISTENING module
2. **Questions text + options** generated by Gemini API (free)
3. **Audio automatically generated** by EdgeTTS (free)
4. **Audio uploaded to MinIO** and linked to question
5. **Validation shows progress**: ⏳ Generating → ✓ Ready
6. **Candidates can take assessment** with complete audio content

## Troubleshooting

### EdgeTTS server not running
```
Error: Failed to connect to http://localhost:5001/tts
```
**Solution:**
```bash
# Check if running
curl http://localhost:5001/health

# Start if not running
python edge-tts-server/app.py

# Or use Docker
docker run -p 5001:5001 edge-tts-server
```

### "EdgeTTS service not available"
- Verify EdgeTTS server is running (`/health` endpoint)
- Check `EDGE_TTS_API_URL` environment variable
- Verify network connectivity between backend and EdgeTTS
- Check backend logs for connection errors

### Audio generation is slow
- First request is slower (warmup)
- Long text (1000+ characters) takes longer
- Check system resources (CPU/memory)
- Text rate > 2.0 might cause issues

### No audio in question
1. Check backend logs for generation errors
2. Verify MinIO is running and accessible
3. Check database for `audio_generation_status`
4. Retry audio generation via admin interface
